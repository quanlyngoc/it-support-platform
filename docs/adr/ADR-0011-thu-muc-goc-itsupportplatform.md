# ADR-0011: Thư mục gốc `D:\ITSupportPlatform`

- Ngày: 02/10/2026
- Trạng thái: Đã duyệt

## Bối cảnh
Chủ đầu tư đổi tên thư mục gốc so với tài liệu (`D:\Platform`).

## Quyết định
Dùng `D:\ITSupportPlatform` cho repo và mọi đường dẫn trong tài liệu, cấu hình.
