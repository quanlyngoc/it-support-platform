Đang làm tốt, phải mang sang hệ mới

  • Cài/cập nhật agent qua Task Scheduler tách rời, watchdog 1 phút, kiểm Client_Manager.exe sau cài.
  • Cập nhật theo đợt: theo phòng, theo phần trăm, công tắc All Update, trang Update Client.
  • Lệnh có command_id + ACK + gửi lại 3 lần; agent chống chạy đúp.
  • Absolute Sync số online (ghi đè số tuyệt đối, cấm cộng dồn).
  • Cache RAM cho đường nóng (phòng của máy, khoá tài khoản, phiên đơn thiết bị).
  • Không tự xoá máy: machine_events + computers_archive.
  • Đăng nhập 1 thiết bị, giới hạn IP theo tài khoản, nhật ký tách hệ LAB/HSK/THI.
  • Thumbnail màn hình qua RFB từ winvnc (vượt được SEB), VNC qua relay agent-gọi-ra.

Điểm nghẽn mà tái cấu trúc giải quyết

  • SQLite là C-extension: giữ khoá ghi qua điểm nhường gevent làm treo cả hub (bài học 10.16).
  • UI/HUB hai tiến trình: state RAM không chia được, đã gây lệnh "rơi vào hư không" (13/09).
  • Trình duyệt giữ JS cũ (fbrowser.js, chatbox.js, favicon): nhiều lần "sửa rồi không ăn".
  • Web không nháy được taskbar khi có tin nhắn (giới hạn trình duyệt).
  • Một tệp 6.123 dòng: sửa một chỗ dễ vỡ chỗ khác, không có test tự động.
  • Chỉ phục vụ được một tổ chức; không có định danh agent mạnh (máy nào gửi nhịp tim cũng được nhận).

G1. Ngữ cảnh tổ chức và lớp Repository bắt buộc

tenant_id được gắn vào g.ctx lúc xác thực. Nghiệp vụ không bao giờ tự đọc tenant_id từ request. Mọi collection của tổ chức chỉ truy cập qua TenantRepo; một test quét mã nguồn sẽ báo lỗi nếu thấy db.<collection>.find( ngoài lớp repo.

# platform-core/app/tenants/repo.py
class TenantRepo:
    collection: str                              # vd. "computers"
    def __init__(self, db, tenant_id):
        self.col, self.tid = db[self.collection], tenant_id
    def _q(self, q=None):
        q = dict(q or {}); q["tenant_id"] = self.tid; return q     # luôn ép tenant
    def find(self, q=None, **kw):  return self.col.find(self._q(q), **kw)
    def get(self, _id):            return self.col.find_one(self._q({"_id": _id}))
    def insert(self, doc):         return self.col.insert_one({**doc, "tenant_id": self.tid})
    def update(self, _id, patch):  return self.col.update_one(self._q({"_id": _id}), {"$set": patch})

# dùng trong route:  ComputerRepo(db, g.ctx.tenant_id).get(device_id)

G4. Trạng thái online không ghi CSDL mỗi nhịp tim

G6. Bộ tương thích agent cũ + canary bằng Caddy

Agent 2.7.5.x kết nối tới cùng địa chỉ HTTPS như hiện nay. Caddy quyết định gửi tới hub cũ hay Core mới theo IP nguồn. Agent không biết mình đang nói chuyện với server nào, nên không có gì phải cài trên máy trạm.

# Caddyfile, trong khối site :5443 — đặt TRƯỚC "handle @hub"
@core_canary {
    client_ip 10.x.y.15/32                 # bước 1: một máy thử
    # client_ip 10.x.y.0/24               # bước 2: thêm dải IP của một phòng
    not header User-Agent *Mozilla*        # CHỈ agent; trình duyệt của GV ngồi máy đó vẫn về web cũ
}
handle @core_canary {
    reverse_proxy <IP-VM-Core>:7009
}
# Quay lui: xoá khối trên → caddy validate → caddy reload (vài giây, không gián đoạn máy khác)
Ba điều kiện bắt buộc (1) Giữ nguyên chứng thư TLS của cổng 5443, vì agent cũ ghim chứng thư (quyết định đã ghi: không xoay khoá máy chủ). (2) Kiểm User-Agent thật của agent trong log Caddy trước khi dùng điều kiện not header User-Agent *Mozilla*. (3) Kiểm thứ tự khối bằng caddy adapt --pretty: khối canary phải đứng trước khối @hub.

G7. Lưu trữ tệp

G8. Tích hợp hệ thi (ThiHSK, ThiPM)

Giữ nguyên đường dẫn và định dạng /internal/*. Giai đoạn on-prem giữ X-Internal-Token + allowlist IP máy chủ hệ thi. ## 4. Tổ chức (tenant), xác thực, phân quyền

- Đăng nhập Desktop: **Mã tổ chức + tài khoản + mật khẩu** (+ TOTP nếu bật). Desktop nhớ mã tổ chức lần trước.

  KHÔNG ghi Mongo mỗi nhịp tim.

- Bộ cài `PhenikaaITMonitor-Agent-Setup-<ver>.exe` (Inno Setup 6.7): `AppId=Phenikaa IT Inventory` (bằng giá trị ngầm định
  của bộ cài cũ), `DefaultDirName={autopf}\PhenikaaIT`, `PrivilegesRequired=admin`; giữ tên task `PhenikaaITMonitor`
  (onstart, SYSTEM) + `PhenikaaITMonitorWD` (1 phút) → **cài đè tại chỗ lên agent 2.7.5.x, không để lại hai bản**.
- Tham số: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SERVER=<địa chỉ> /ENROLL=<mã> /LOG="C:\ProgramData\PhenikaaIT\install.log"`;
  `/SERVER`, `/ENROLL` đọc bằng hằng `{param:...}` và ghi vào `C:\ProgramData\PhenikaaIT\agent.json`.
- Bước cuối bộ cài: chạy task và **kiểm `Client_Manager.exe` đang chạy**. Gỡ: `unins000.exe /VERYSILENT` (giữ `agent_id`).
- Cập nhật cho máy đang có agent luôn qua Core + cài bằng task tách rời (luật §0.2), không gọi bộ cài như tiến trình con.

MKết luận kỹ thuật chuyên môn

Ý kiến chuyên môn trên cơ sở đối chiếu đặc tả V2, mã nguồn và số liệu vận hành thực tế của hệ thống hiện tại.

1. Về định hướng của đặc tả

Định hướng của đặc tả là đúng và phù hợp với quy mô bài toán. Modular monolith một Core, một CSDL dùng chung phân tách bằng tenant_id, agent tự kết nối ra, Core là điểm duy nhất chạm dữ liệu: đây là mô hình được MongoDB khuyến nghị cho SaaS đa tổ chức và đủ cho vài nghìn máy trạm mỗi tổ chức. Việc cấm microservice, Redis, message queue và Kubernetes là hợp lý ở quy mô hiện tại (889 máy, khoảng 437 nhịp tim/giây lúc đỉnh).

2. Về tính khả thi

Phương án khả thi về kỹ thuật với công nghệ hiện hành (10/2026): Python 3.14, Flask-SocketIO 5.6, MongoDB 8.0, Tauri 2, React 19, Vite 8, Nuitka 4.2, Inno Setup 6.7 đều ở trạng thái ổn định. Phần khó nhất không phải viết mã mà là chuyển 889 máy đang chạy sang nền tảng mới mà không mất kết nối. Đặc tả V2 chưa giải quyết điểm này. Phương án giải quyết bằng bộ tương thích agent cũ và định tuyến canary theo dải IP tại Caddy: chuyển và quay lui chỉ bằng cấu hình, không chạm máy trạm.

3. Điều kiện tiên quyết

  1. Ban hành đặc tả V3 đã sửa 17 điểm (mục C) và có 18 bổ sung (mục D); AI chỉ được dùng V3.
  2. Hạ tầng MongoDB replica set 3 node có sao lưu đã khôi phục thử.
  3. Cảnh báo tự động khi số máy online tụt, chạy trước mọi thay đổi chạm máy trạm.

  • Core: Python 3.14 (dự phòng 3.13) + Flask 3.1 + APIFlask + Flask-SocketIO 5.6 + gevent + PyMongo 4 bản đồng bộ. Không dùng Motor (đã hết hỗ trợ 14/05/2026).
